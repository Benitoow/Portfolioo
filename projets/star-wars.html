01 / Le brief

L’univers est libre.
La contrainte, PHP.

La SAE 1.05 demandait un site rendu côté serveur en PHP, avec un fichier JSON pour stocker le contenu. J’ai choisi Star Wars pour le thème.

Personnages, vaisseaux et citations partagent la même source de données. Les pages et la galerie se construisent à partir de ce fichier ; le formulaire est traité côté serveur.

03 / Sous le capot

Un fichier.
Plusieurs pages.

Le travail portait autant sur l’organisation des données que sur l’intégration des pages.

  1. 01

    Les données

    Le fichier JSON regroupe les personnages, les vaisseaux et les citations. Il sert de source commune aux pages.

  2. 02

    Le rendu PHP

    Chaque page lit ce fichier et produit son HTML à l’aide de boucles. La galerie suit la même logique : un élément ajouté au JSON rejoint l’affichage.

  3. 03

    Le formulaire

    Le serveur contrôle les données reçues et renvoie les messages d’erreur ou de confirmation via les paramètres GET. Le traitement fonctionne sans JavaScript.

05 / Ce que j’en garde

Le contenu
a sa propre place.

C’est surtout la séparation des données et de leur affichage qui m’a marqué. Modifier un contenu dans le JSON évite d’aller le réécrire dans chaque page.

Le formulaire m’a aussi appris à penser le retour utilisateur côté serveur. Une validation et un message lisible restent nécessaires, même sans JavaScript.
