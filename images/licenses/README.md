# Project icons

`../project-icons.svg` contains selected static SVGs from:

- Line MD, by Vjacheslav Trushkin: https://github.com/cyberalien/line-md/tree/main/svg-static (MIT; see `line-md-MIT.txt`).
- Hugeicons free icons: https://github.com/hugeicons/hugeicons/tree/main/icons (MIT; see `hugeicons-MIT.txt`).

Original path geometry is retained. SVG roots are converted to symbols; Hugeicons strokes use `currentColor` to follow the portfolio palette. No external script, font, API or package is loaded. Static variants respect reduced-motion settings without additional animation code.
